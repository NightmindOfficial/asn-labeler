# Security

Do not post credentials, private documents, production databases or exploitable
vulnerability details in public issues. Contact the maintainer through
[nightmind.dev](https://nightmind.dev) to arrange a private reporting channel
before sharing sensitive details. No response-time or long-term support guarantee
is currently offered.

Use supported releases and follow security-update notices. The server can reject
new printing on known-unsafe versions while accepting completion acknowledgements.
An unknown safety status does not prove that a version is secure.

Keep separate client/admin keys and use HTTPS outside trusted local environments.
Back up the database. Restoring old state can allow duplicate ASNs for labels
printed since the backup: stop clients and reconcile before restoring.
